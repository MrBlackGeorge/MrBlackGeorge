### Featured Projects

#### FitTrack – Fitness and Nutrition Tracking App (Diploma Thesis)
- **Tech:** Flutter, NestJS, MongoDB, Ollama
- **Highlights:**
  - Full‑stack mobile app for workout and nutrition tracking
  - Local LLM (Gemma 4 12B via Ollama) that generates personalized training recommendations, self-hosted with no external API calls
  - Custom design system for the app's user interface

#### [OffTheBench](https://github.com/MrBlackGeorge/OffTheBench) – Full‑Stack Sports News Platform
- **Tech:** Django, MySQL, JavaScript, Guardian News API, live sports-data API
- **Highlights:**
  - Built in a team of four
  - Role‑based access (User, Editor, Administrator) with protected editorial workflows
  - Guardian News API for article propagation and a live sports-data API for match scores
  - Community forum and relational schema design in MySQL Workbench

#### [Printing House](https://github.com/MrBlackGeorge/printing_house) – Print Shop Platform
- **Tech:** MongoDB, Express, Angular, Node.js (MEAN stack), Stripe
- **Highlights:**
  - Four user roles (individual/company customer, printer, administrator) with registration approval and password reset via a time‑limited link
  - Stripe card payments with server‑side verification, PDF invoices sent by email, and a Leaflet map with print shop geocoding
  - Public procurement with print shop bids and automatic selection of the best offer, using atomic locking to prevent duplicate invoices under concurrent requests
